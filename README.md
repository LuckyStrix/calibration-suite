# calsuite

Camera sensor, lens and display calibration with provenance.

This is a placeholder. Wave 1 (foundation: scaffolding, core contracts,
`formats/`, `report/`, `capture/`, `devices.py`, `synth/sensor.py`, CI) is
built; camera/lens/display analysis (Wave 2) and the full CLI/`doctor`/
`demo`/install workflow (Wave 3) are not yet. The integration wave writes
the real README (install instructions, workflow per phase, what's not
built) once those exist.

See `docs/design.md` for the full plan and `docs/implementation-plan.md`
for how it's being built.
